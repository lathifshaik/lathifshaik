# Fonts

These fonts come from Google Fonts. Each one is licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org).

- Archivo Black: display headings
- Caveat: hand-written accents
- Inter: body text and labels
- JetBrains Mono: code and terminal text

`design/build.py` embeds subsets of these fonts in the SVGs under `assets/`.
